Notes

The builder's [builder-hover.mjs](builder-hover.mjs) (output at the end of hover-frames.txt) agrees (lead − dialog 4–45 ms) but times from Node and printed a negative dialog time for Lisbon (`dialog -2428ms`), a clock/ordering glitch also present in the baseline (`close -2348ms`); its numbers alone shouldn't be trusted.
- `naturalWidth` on a srcset tile is density-corrected (a 640 copy in a 501px slot reads 501), so the tile file is identified by `currentSrc`, and the viewer check relies on the viewer `img` having no srcset.
- Measure script run from docs/research/atlas-perf/measure.mjs in the main tree (it is not on the stage-2 branch, which was cut from b1455c6).
